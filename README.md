# Operating Systems – Course Repository

This repository contains all theoretical and practical materials from the **Operating Systems** course.

It includes lecture slides in both **Arabic** and **English**, practical **Linux/Ubuntu laboratories**, assignment solutions, and the final project developed using Linux command-line tools and system administration concepts.

---

# 📚 Course Overview

The course introduces the fundamental concepts of operating systems and explains how modern computer systems manage hardware resources, processes, threads, memory, storage, and system services.

In addition to the theoretical foundation, the practical part of the course focuses on Linux environment administration, command-line operations, shell scripting basics, system configuration, and applying operating system concepts through hands-on laboratories and projects.
